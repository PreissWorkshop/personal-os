# Pitfalls - what exposes a translation

Each line: ✗ what not to write -> ✓ what to write, and why. Most of these
come from real Icelandic mail in the corpus or from the website templates.

## Address and greeting

- ✗ "Getið þér sent mér myndir?" -> ✓ "Getur þú sent mér myndir?" /
  "Gætir þú sent mér myndir?" - þéringar are dead in everyday Icelandic.
- ✗ "Sæl/l Jón Jónsson," -> ✓ "Sæll Jón," - no slash form, no
  surname in a greeting.
- ✗ "Kæri herra Jónsson," -> ✓ "Sæll Jón," - titles and surnames are
  not used in address.
- ✗ "Sæl Anna Björk Jónsdóttir," -> ✓ "Sæl Anna," (first name; "Anna
  Björk" if she uses both).
- ✗ "Kæri viðskiptavinur," in a personal reply -> ✓ the name, or "Góðan
  dag,". The generic form is for mass mail only.
- ✗ Writing "þú" to a design studio that wrote "við" -> ✓ "þið/ykkur".

## Closing

- ✗ "Vinsamlegar kveðjur," / "Bestu kveðju," -> ✓ "Bestu kveðjur," /
  "Með kveðju," / "Kær kveðja,".
- ✗ "Kkv," as the closing of a first reply or an offer -> ✓ "Bestu
  kveðjur,". Abbreviations belong inside an active thread.
- ✗ "Regards," + English signature under Icelandic text -> ✓ one language,
  one closing.

## Numbers, money, dates

- ✗ "1,234,500 kr" -> ✓ "1.234.500 kr."
- ✗ "kr 450.000" / "450000 ISK" -> ✓ "450.000 kr." (ISK only for foreign
  readers).
- ✗ "750þ", "1.5-2mil", "+vsk" in client text -> ✓ "750.000 kr.",
  "1,5–2 m.kr.", "án vsk.".
- ✗ "24 %" -> ✓ "24%".
- ✗ "með VSK" mid-sentence -> ✓ "með vsk." (VSK only in table headers).
- ✗ "2026-09-18" in prose -> ✓ "18. september 2026".
- ✗ "18. September", "Miðvikudagur" mid-sentence -> ✓ lowercase months and
  weekdays.
- ✗ "10 AM", "10.00 o'clock" -> ✓ "kl. 10:00".
- ✗ "2008mm", "50m" -> ✓ "2008 mm", "50 m".
- ✗ "96.6 x 40 x 4 cm" -> ✓ "96,6 × 40 × 4 cm".
- ✗ Price without VAT status to a private client -> ✓ always "með vsk.".

## Words and idioms that smell of English

- ✗ "Ég vona að þessi tölvupóstur finni þig vel." -> ✓ delete. Nobody
  writes this in Icelandic.
- ✗ "Við bjóðum upp á lausnir fyrir ..." -> ✓ say what you make: "Við
  smíðum innréttingar, hillur og sérlausnir eftir máli."
- ✗ "Ekki hika við að ná í mig hvenær sem er!" -> ✓ "Láttu mig vita ef
  eitthvað er óljóst." ("Ekki hika við að hafa samband ef spurningar
  vakna." is correct but corporate.)
- ✗ "Ég er spenntur að vinna með þér!!!" -> ✓ "Ég hlakka til að vinna
  þetta með ykkur." (calm, one line, no marks).
- ✗ "Frábærar fréttir!" as an opener -> ✓ "Flott." / "Gott að heyra."
- ✗ "offer", "invoice", "deadline", "budget", "sample", "layout", "render",
  "mockup", "please" left in -> ✓ tilboð, reikningur, skilafrestur,
  kostnaðarrammi, sýnishorn, uppsetning/skipulag, tölvumynd, sýnismynd,
  endilega/vinsamlegast.
- ✗ "wrappa hurðirnar" in an offer -> ✓ "filma hurðirnar" ("wrappa" is
  fine in speech and chat).
- ✗ "Þú" capitalised mid-sentence -> ✓ "þú".
- ✗ "Takk fyrir þolinmæðina!" as a reflex -> ✓ only when there was a real
  wait, and then say what happened.

## Grammar traps

- Names in the wrong case: "Sæll Jón" (nom.), "tilboð fyrir Jón" (acc.),
  "frá Jóni" (dat.), "til Jóns" (gen.); "Sæll Guðmundur", "frá Guðmundi",
  "til Guðmundar". Unsure of a name's
  declension -> restructure so the name stays nominative, or check BÍN
  (bin.arnastofnun.is). Never guess a genitive.
- Agreement: "ánægður" (m) / "ánægð" (f) / "ánægð" (n pl.); "búinn" /
  "búin"; "velkominn" / "velkomin" / "velkomin" (pl.).
- "tilboð í" + accusative (tilboð í hillur, í verkið, í filmun); "tilboð
  um" is not used for work.
- "með fókus á" + dative (á innréttingum); "í kringum" + accusative (í
  kringum 3 m.kr.); "á bilinu ... til ..." for ranges in prose.
- Compounds are one word: "verðdæmi" not "verð dæmi", "glanslakk" not
  "glans lakk", "eldhúsinnrétting", "kostnaðaráætlun".
- "Sent" as a mail footer is fine ("Sent 18. september" = past
  participle), but "Sent by" is not.

## Tone

- ✗ Superlatives without proof ("besta verðið á markaðnum") -> ✓ facts.
- ✗ Exclamation marks in an offer -> ✓ none.
- ✗ An excuse paragraph before a delay -> ✓ what happened, new date, next
  update.
- ✗ Studio Esja: "lúxus", "einstakt tækifæri", "takmarkað upplag!!!",
  "ótrúlega fallegur" -> ✓ the material, the making, one sensory
  observation, the size, the care.
- ✗ Inventing a fact to fill a sentence (capacity, dishwasher, lead time,
  a rate) -> ✓ leave it out or ask.
